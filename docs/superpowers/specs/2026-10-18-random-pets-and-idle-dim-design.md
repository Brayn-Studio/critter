# 随机宠物与空闲淡化 — 设计文档

日期：2026-10-18
状态：已实现。

> 记号：**【用户定】** 用户明确做的决定；**【Claude 定】** Claude 代为决定、用户没有逐条确认的。

## 1. 意图

两个设置项【用户定】：

- **随机宠物**：同时开多个会话时，给每个会话随机分配一个形象，减少单调。
- **空闲淡化**：空闲时宠物变灰、半透明的效果太强，交给用户自己调。

## 2. 随机宠物

### 规则【Claude 定】
- 打开后，每个会话第一次出现时，从所有可选形象（设置里的形象列表，含 Clawd 和 `~/.critter/skins/` 里的自定义皮肤）中分到一个：在**当前在场的会话用得最少的那些形象**里等概率随机挑。所以形象够分时一排里不重样，会话比形象多时才重复。
- 分到的形象在这个会话存在期间不变；会话结束就忘掉。分配只记在内存里，Critter 重启后重新分。
- 某个形象不再可用（比如自定义皮肤被删）时，用它的会话重新分。
- 只有 `tickMs` 和默认形象相同的皮肤进入随机池（一排 Critter 共用一个时钟）。自带的五个都是 60 ms。
- 关掉后全部换回设置里选中的那一个。开关、或可选形象有变化时，像换形象一样原地重建宠物视图。
- 菜单栏图标始终是选中的那个形象。

### 实现
- 分配是 CritterCore 里的纯函数（`SkinAssigner`），用 `MotionRNG`，可用固定种子测试。
- `FlockView` 从“一排共用一个形象”改成“每只各穿各的”：每只 Critter 用自己的形象创建 `MotionActor` 和精灵图层（每个形象一份贴图缓存）；交互和编排里用到的动作名（按下、拎起、放下、来回蹭、加入、离开、显示、隐藏、入座……）都取这只自己的形象的 `interactions`，因为 Clawd 和其他四个的动作名不同。合并成一堆时，后排画坐在那里的会话自己的形象。
- 关闭时走原来的单形象路径，行为和以前完全一样。

## 3. 空闲淡化

空闲、出错的 Critter 和合并后的后排用的是 `dim` 色调：每个颜色和中灰各混一半，不透明度乘 0.85。

- 加一个强度 `s`（0–100%）：混灰比例 `0.5·s`，不透明度 `1 − 0.15·s`。`s = 100%` 与原来逐字节相同，`s = 0` 就是原色、完全不透明。
- 设置 `idleDim`，默认 100%（保持原样）【Claude 定】，滑块每格 5%，拖动时实时生效（像改大小一样重建宠物视图）。
- 合并后的后排另外有一层表示远近的透明度（0.55 / 0.75），不受这个设置影响。

## 4. 验收

1. `swift test` 全部通过，含分配规则和淡化强度的单元测试。
2. 真实 App：打开随机宠物后几个会话各是不同形象，按下、拖动、加入、离开、合并都用各自的动作；关掉后全部换回选中的形象。
3. 空闲淡化拖到 0% 时空闲的 Critter 和忙碌时一样鲜艳，100% 时和以前一样。
