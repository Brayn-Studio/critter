# Clawd 动画 v2 — 设计文档

日期：2026-10-17
状态：动作设计已由用户在可交互预览里逐项确认；本文把它落到 App 的规则写清楚。

> 记号：**【用户定】** 用户明确做的决定；**【Claude 定】** Claude 代为决定、用户没有逐条确认的；未标记的是两边都认可的事实。

---

## 1. 意图

第一版宠物只有 3 个像素帧和 4 种整体位移（跳、摇、呼吸、静止）。用户要一套完整的动画：静息、工作、提问（申请权限）、完成、出错、各种交互（悬停、拖动、点击……）、展开与合并，风格参考 Anthropic 官方账号视频和 Claude Code CLI 里的 Clawd。

设计已经在可交互预览里定稿，用户确认“都很满意”：

- 线上预览：https://claude.ai/artifact/L1BanpyKFyKyacWNqDXvdq
- 仓库副本（**动作、像素、时间的唯一依据**）：`docs/superpowers/specs/2026-10-17-clawd-motion-preview.html`
- 由预览数据生成的皮肤清单：`docs/superpowers/specs/2026-10-17-clawd-manifest-v2.json`（schema 2，见 §3；生成脚本 `scripts/dev/make-manifest-from-preview.js`），实现时原样放到 `Skins/clawd/manifest.json`

实现的目标是：App 里的每个动作，逐格、逐像素和预览一致。预览的 JS（`Actor`、`enterState`、`brainStep`、`travelKeys`、`followStep`、`gazeFor` 等）就是行为参考实现；本文把这些规则写成文字，两者冲突时以预览为准，并在实现中指出。

## 2. 目标 / 非目标 / 反目标

### 目标
1. 预览里的全部动作出现在 App 里：每个状态的进场 + 循环 + 随机小动作；睡着/被吵醒；按工具区分的工作动作（抱笔记本、思考、读、跑命令、派子任务）；常驻的橙色 `!`；悬停、目光跟随、来回蹭、按下/点击（boop）、拎起来、其余的跟着走、放下；展开、合并（逐只入座）、新会话加入（探头）、会话结束（挥手沉下去）、显示/隐藏（从天而降/沉下去）。
2. 动画全部由 `Skins/clawd/manifest.json` 描述；换皮肤不改代码（沿用第一版 §6.6 的要求）。引擎里只写“规则”（怎么播放、怎么跳、怎么跟随），不写具体某个动作的像素和时间。
3. 系统“减少动态效果”打开时：每个状态停在一个代表姿势，不放粒子，移动直接到位。

### 非目标
- 新皮肤、新形象、音效改动。
- 侧面/转身视角（CLI 的 turn、coin-hop 没有采用）。

### 反目标【用户定，沿用第一版】
- **占内存/CPU 太多。** 活动监视器“内存”≤ 50 MB（5 个会话展开、有动画）；没有动作在变化时 CPU 接近 0；持续动画（如敲笔记本）平均 < 1%。
- **不稳定、拖不动、挡屏幕。** 任何动画都不能让窗口卡住、无法点击穿透或跑出屏幕。动画进行中收到新的会话数据，不能丢、不能乱序、不能卡死。
- **动画和真实状态脱节。** 编排（展开、加入、离开）可以让窗口大小晚一点生效，但状态本身（谁在等确认）必须立即显示。

## 3. 皮肤清单 schema 2（契约）

清单已由预览数据生成（`docs/superpowers/specs/2026-10-17-clawd-manifest-v2.json`），实现时原样成为 `Skins/clawd/manifest.json`，`SkinLoader.builtinJSON` 与它逐字相等（沿用现有测试）。字段：

| 字段 | 含义 |
|---|---|
| `schema` | `2`。schema 1 的文件视为无效皮肤，回退到内置。 |
| `tickMs` | 一格的时长，60。 |
| `grid` | `[18, 10]`：基准框宽高，单位“像素格”（下称 u）。像素是**正方形**；原 18×5 的瘦高像素拆成上下两格，静止形象不变。 |
| `palette` | 字符 → 颜色。`.` 透明。 |
| `parts` | 部件：`at` 是左上角在基准框里的坐标（可为负，可超出 18×10），`rows` 是像素行。 |
| `poses` | 姿势 = 部件名列表，按顺序叠画（后画的盖住先画的）。 |
| `glyphs` | 粒子/头顶标记用的小像素图，`#` 取调用方给的颜色。 |
| `clips` | 动作 = 关键格列表 `[姿势, 格数, dx?, dy?, 特效?]`。dx/dy 单位 u，dy 正为向上，**dy 负为沉入地面**（见 §4.1 地面裁切）。特效在该关键格开始时触发一次。 |
| `effects` | 粒子特效：`particles`（每次触发全部发出）或 `cycle`（每个 Clawd 每次触发轮到下一组）。数值字段可以是数字或 `[min, max]`（均匀随机；`life` 取整数闭区间）；`count` 重复；`colors` 按粒子序号轮流；`pop`、`sway`、`shrinkTo` 见 §4.6。 |
| `accessories` | 头顶标记：`spinner`（按余弦节奏换帧）、`q`（跳动）、`check`（定时闪 ✦）、`bang`。 |
| `states` | 五个状态各自的 `enter` / `loop` / `tint` / `accessory` / `still`（减少动态效果时的姿势），以及可选的 `fidget`、`sleep`、`impatient`、`badge`、`seen`、`stillDy`；`running` 另有 `variants`（每个变体自己的 `loop`、可选 `enter`/`exit`/`prop`）和 `defaultVariant`。 |
| `interactions` | 引擎在交互和编排中要用的动作/姿势/特效名：`notice`、`pet`、`petEnd`、`press`、`boopEnd`、`held`、`heldStill`、`drop`、`blink`、`join`、`leave`、`appear`、`vanish`、`hop`、`land`、`blinkPose`、`landDust`、`walkLeft`、`walkRight`、`look*`。 |
| `props` | 跟动作绑定的道具，目前只有 `juggle`（三颗球）。 |

校验（`SkinValidator`）至少检查：所有引用（部件、姿势、动作、特效、字形、颜色字符）都存在；格数 > 0；五个状态齐全；`interactions` 每个名字都能解析到对应类别。

## 4. 运动引擎规则（ClawdCore，纯逻辑）

坐标约定：每个 Clawd 有一个锚点 = 基准框左下角所在的地面点。基准框列 0…17、行 0…9，第 10 行就是地面。粒子、头顶标记都用同一套 u 坐标，相对锚点。

### 4.1 播放
- 每个 Clawd 有三层：**基础循环**（状态的 loop）、**模式循环**（交互占用，如 `held`、`pet`、`press`，可空）、**单次动作**（进场、小动作、交互反馈、移动）。当前播放优先级：单次 > 模式 > 基础。
- 单次动作播完，回到“模式循环（若有）否则基础循环”的开头，并以 `true` 回调完成；被新的单次动作或取消打断时以 `false` 回调。
- 每格推进一次；关键格的格数用完进入下一格；循环播完回到第一格。
- **地面裁切**：姿势像素在加上 dy（及 lift）之后落在第 10 行及以下的，不画。这就是“蹲下 = 下沉、脚被地面挡住”。
- `lift`（被拎起的高度，u）与 dy 一起参与裁切；`lag`（被拎时身体的甩动，u）只平移。
- 目光：Clawd 处于“空闲且醒着”或“做完了”、且没有单次动作和模式循环时，用 `look*` 姿势替换当前姿势（时间不变）。

### 4.2 状态切换（`enterState`）
1. 若离开的是 `running`，先播当前变体的 `exit`（如合上笔记本）；
2. 设置新状态的基础循环（`running` 用当前变体的 loop）、`tint`、头顶标记、道具；
3. 播进场：`running` 用 `变体.enter ?? 状态.enter`，其他状态用 `enter`；有 exit 时等 exit 播完（`true`）且状态没再变，才播 enter；
4. 没有 enter 时取消正在播的单次动作；
5. 初次出现（App 启动、加入时）用“安静”方式进入：只设循环，不播 enter；
6. 计数器清零：空闲计时、等待计时；随机小动作倒计时取 40…90 格。

### 4.3 随机小动作、睡着、着急
- 有 `fidget` 的状态：倒计时到 0 且没有单次动作时，按权重挑一个动作播放，然后在 `every` 范围内重新取倒计时。
- 空闲：醒着时计时，满 `sleep.after` 格（2 分钟）后进入睡着：播 `doze`，基础循环换成 `sleep.loop`，头顶标记隐藏，不再有小动作。被指针悬停、或状态改变时醒来：基础循环回到 `loop`，播 `wake`。
- 等待：满 `impatient.after` 格（30 秒）后基础循环换成 `impatient.loop`，`!` 的跳动周期换成 `impatientHopEvery`。
- 交互占用（模式循环）、移动中、跟随中时，以上计时都暂停。

### 4.4 工作变体（按工具）
- 状态文件新增可选字段 `activity`：`think` / `laptop` / `read` / `bash` / `juggle`（§5.6）。缺失或未知 → `defaultVariant`（`laptop`）。
- **防抖【Claude 定】**：新变体要持续 ≥ 20 格（1.2 秒）、且当前变体已经显示 ≥ 40 格（2.4 秒），才切换。原因：每次工具调用前后都会有一次“思考”，不防抖的话笔记本会一秒开合好几次。
- 切换时：播旧变体的 `exit`（若有），再播新变体的 `enter`（若有，只用变体自己的，不用状态级的 `work_enter`），然后换循环。

### 4.5 头顶标记与常驻 `!`
- 位置：水平居中在第 9 列（`x = round(9 − 宽/2)`，.5 向上取整），底边在第 −2 行；`spinner` 在 5 行高的框里垂直居中。随身体的 dx 不动，随 lag、lift、跟随偏移移动。
- 不画的情况：没有标记；合并成一堆时（计数小标签占了这一行）；被拎起；移动中；睡着；当前关键格 dy ≤ −6 或 ≥ 7。
- `spinner`：帧号 = `round((1 − cos(2π·t/periodMs)) / 2 × 5)`，t = 格数 × tickMs；减少动态效果时画 `reduced`。
- `q`：每 `bobEvery` 格交替上移 1 u。`check`：每 `twinkleEvery` 格触发一次 `twinkle` 特效。
- 等待状态的常驻 `!`（`badge`）：在第 `x` 列、底边第 −2 行；从进场动作开始那一刻出现（安静进入或减少动态效果时立即出现），出现后前 2 格上移 1 u；之后每 `hopEvery` 格（着急时 `impatientHopEvery`）有 2 格上移 1 u；一直留到离开等待状态。

### 4.6 粒子
- 每格（dt = 0.06 s）：`vy += ay·dt; x += vx·dt; y += vy·dt; age += 1`，`age ≥ life` 时移除。
- 绘制位置取整；`sway` 时 x 加 `round(sin(age·0.5)·sway)`；`pop` 时前 2 格上移 1；`age > 0.65·life` 时透明度 0.5；有 `shrinkTo` 时过半寿命换成该字形并向右下各偏 1。
- 粒子坐标相对 Clawd 当前锚点（含 lag/lift/跟随偏移），所以跟着 Clawd 走。
- 减少动态效果时不发粒子。

### 4.7 影子与道具
- 影子：dy + lift > 0 时在地面画一条半透明黑（不透明度 0.28），宽 10/6/2 u（高度 ≤2 / ≤5 / 更高），高 max(2 pt, u/2)，水平居中在身体下。
- `juggle` 道具：仅当前播放的是变体的 loop 时显示；第 i 颗球（i = 0,1,2）相位 `ph = ((格数 + 6i) mod 18) / 18`，位置 `x = 3 + 11·ph`、`y = −2 − round(7·sin(π·ph))`（取整），颜色按 `props.juggle.colors`。

### 4.8 移动（展开、合并、挪位）
- 从相对目标的 (D, Dy) u 跳到 (0, endDy)：先停 `delay` 格；每跳 4 格（姿势 hop、hop、hop、land，额外抬高 2、3、2、0），一共 `ceil(|D| / hopLen)` 跳，每格按进度线性插值 D 和 Dy→endDy。
- 落地：`endDy = 0` 时 `[land 2 格 下沉 2 + landDust] [land 1] [blinkPose 1]`；`endDy > 0`（坐进那一堆）时 `[land 1 格 endDy−1 + landDust] [land 1 格 endDy + 入座]`，“入座”把这只调暗、透明度 0.55（最后排）或 0.75、放到对应层。
- hopLen：桌面 14 u，展开/合并演示同 14 u【Claude 定，预览卡片里用的是 12】。
- 移动中不画头顶标记、不跑计时、不响应目光；它的气泡和标签隐藏，落地后再淡入。

### 4.9 合并时逐只入座【用户定】
- 离那一堆最近的先出发，每只错开 2 格。
- 最急的那只（lead）站最前面（不调暗）。其余的按出发顺序入座：第 1 只坐最后排（第 nb 排），第 2 只坐第 nb−1 排……，nb = min(2, 会话数 − 1)；再多的都坐第 1 排，后到的盖住先到的（先到的那只隐藏）。
- 第 k 排的位置：比 lead 右移 4k u、上移 k u（与静态的那一堆完全一致）。
- 全部到齐后才切换成“合并”布局，此时用静态的那一堆替换入座的 Clawd，画面不能有任何跳变。
- 展开时反过来：入座的从各自的座位起跳，lead 从前面起跳；恢复正常颜色和循环。

### 4.10 拖动与跟随【用户定】
- 只有被按住的那只：先 `press`（眯眼蹲下扬尘），移动超过 3 pt 进入 `held` 模式，lift = 3 u，lag = clamp(−水平速度/3, −3, 3) u，没有移动时每格向 0 收 1。
- 其余可见的 Clawd 进入跟随：窗口移动 (dx, dy) 时它们的偏移减去 (dx, dy)，再限制在水平 ±12 u、竖直 ±8 u 以内。每格追 1 u（水平偏移 > 6 u 时追 2 u），竖直每格追 1 u，竖直追平那一格发 `landDust`。
- 跟随中的姿势：竖直偏移 ≥ 1 u → `hop`；否则水平偏移 ≥ 1 u → 朝前进方向走（`walkLeft`/`walkRight` 两帧交替，小跑时每格换一帧，否则每 2 格）；都追平了 → 朝被拎那只的方向看（`lookLeft`/`lookRight`）。
- 松手：被拎的那只 lift、lag 归零，结束模式，播 `drop`；其余的继续追，追平后结束跟随并播 `blink`。
- 合并成一堆时拖动：只有 lead 被拎起，后面那一堆整体跟着窗口走。
- 减少动态效果：被拎的那只停在 `heldStill`，其余不产生偏移。

### 4.11 悬停、目光、来回蹭、点击
- 目光：指针到 Clawd 中心（锚点 + (9 u, −7 u)）的距离 > 170 pt 时不跟随。否则：竖直方向在头顶上方超过 max(28 pt, 1.1·|水平距离|) → `lookUp`；水平 < −6 u → `lookLeft`；> 6 u → `lookRight`；指针在下方超过 10 pt → `lookDown`；其余 → `lookCenter`。
- 指针进入某只的区域（基准框横向 1…17 u、竖向锚点上方 11 u 到下方 2 pt）：睡着的被吵醒；否则在没有单次动作和模式循环时播 `notice`。
- 来回蹭：在同一只身上，水平移动 ≥ 3 pt 记一次方向，1 秒内反向 ≥ 3 次 → 模式循环 `pet`；离开这只或 0.7 秒没动 → 结束模式、播 `petEnd`。
- 按下：取消单次动作，模式循环 `press`。松开且没拖动：结束模式、播 `boopEnd`，同时执行原来的点击行为（跳回会话；点那一堆则展开）。

### 4.12 减少动态效果
- 每只停在 `still`（睡着时 `sleep.still`，`error` 再下沉 `stillDy`）；被拎时 `heldStill`；目光仍按 §4.11 替换姿势（只有眼睛变化）。
- 头顶标记静止（`spinner` 画 `reduced`，`q` 不跳），常驻 `!` 立即出现且不跳；不发粒子；移动、跟随直接到位；进场、退场、小动作都不播。

## 5. 接入 App

### 5.1 网格与尺寸
- 一个 u = 3 pt × 宠物大小（设置里的缩放）。Clawd 仍是 54×30 pt × 缩放。
- `FlockLayout.Metrics`：头顶标记行高改为 8 u（原 14 pt）；那一堆的错位改为 (4 u, 1 u)（原 (12, 4) pt × 缩放，不是整像素）。

### 5.2 窗口留白（overscan）【Claude 定】
- 动画会画出原来的格子：跳起、举手、彩纸、z、跟随时落后 12 u。窗口四周加透明留白：上 12 u、左右 12 u、下 8 u。留白不接收鼠标（点击穿透只认 `hitRects`）。
- `FlockLayout.Result` 增加 `content`（原来的整块区域）；`size` 和所有矩形都包含留白偏移。定位（`Anchor`、`PositionModel`）一律针对 `content`：锚点记录的是内容的边，夹回屏幕时只要求内容在屏幕内，留白可以伸出屏幕。

### 5.3 编排：窗口什么时候变【Claude 定】
`PetController` 算出新的呈现和布局后不再直接设窗口，而是交给 `FlockView`：`present(presentation, layout, place:)`，由 `FlockView` 在合适的时刻调用 `place()` 改窗口。一次只进行一段编排；编排中又来新数据时：**状态立即生效**（每只 Clawd 立即 `enterState`，气泡文字立即更新），**结构变化**（加入、离开、展开、合并、顺序）排队，当前编排结束后按最新的一份执行。

| 变化 | 做法 |
|---|---|
| 只有状态/文字变化 | 立即 `place()`；列宽变了的（如出现了气泡）跳到新位置。 |
| 展开（一堆 → 一排） | 先 `place()` 到展开布局；所有 Clawd 从那一堆的位置（lead 在前、其余在座位上）按 §4.9 起跳到各自的列。 |
| 合并（一排 → 一堆） | 窗口不变；按 §4.9 入座；全部到齐后 `place()` 到合并布局。 |
| 加入（一排里多了 id） | 先 `place()`；原有的从旧位置跳到新位置；新来的在自己的列播 `join`（探头）。 |
| 离开（一排里少了 id） | 窗口不变，离开的播 `leave`（挥手、沉下去、噗）；播完再 `place()`，剩下的跳到新位置。 |
| 同时有加入和离开 | 先离开，再加入。 |
| 一排 → 一堆且有新 id（第 5 个来了） | 按“合并”处理，新来的直接算进那一堆。 |
| 空 ↔ 一个会话 | 占位的那只直接变成这个会话的 Clawd（反之亦然），不做加入/离开。 |
| 一堆 → 一堆 | 立即 `place()`；lead 换人时直接换状态。 |

- “旧位置”换算到新窗口坐标：`FlockView` 在 `place()` 前后各读一次窗口位置，差值加到旧坐标上。
- 合并的那一堆在展开布局里的位置：`PetController` 先算出合并后窗口会放在哪里（同一套锚点和夹回屏幕规则），`FlockView` 把那一堆的入座位置换算到当前窗口坐标上；没有被夹回时等同于按锚点那一侧对齐。
- 显示/隐藏（`/pet`、菜单栏、快捷键）：显示时先把窗口放出来，每只播 `appear`（错开 90 ms）；隐藏时每只播 `vanish`（错开 60 ms），全部播完再收起窗口。减少动态效果时直接显示/收起。

### 5.4 渲染
- 每只 Clawd 一个容器图层：影子、身体（`contents` = 姿势位图，按“姿势 + 是否调暗”缓存）、道具、粒子（复用的小图层池）、头顶标记、常驻 `!`。全部最近邻放大，关闭隐式动画。
- 时钟【Claude 定】：主线程定时器，60 ms 一格，容差 10 ms。引擎提供“还要多少格才会有画面变化”，没有变化时定时器直接睡到那一格，醒来补走中间的格子（计时器照常累积）；画面没变的格子不提交 Core Animation 事务。窗口隐藏时停表。
- 气泡、标签是普通视图：所属 Clawd 移动/加入中隐藏，落地后淡入；跟随中每格按偏移平移。

### 5.5 交互接线
- 指针位置来自已有的 `ClickThroughController` 全局/本地鼠标监听，转换成 `FlockView` 坐标后用于目光、悬停、来回蹭。只在目光方向或悬停对象变化时更新画面。
- 按下、拖动、松开沿用 `FlockView` 现有的鼠标处理（3 pt 判定拖动），加上 §4.10、§4.11 的动画。

### 5.6 状态文件新增 `activity`
