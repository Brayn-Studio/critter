Critter 动作库

桌面宠物 Critter 的全套动画设计稿：静息、工作、提问、完成、出错、各种交互，以及展开与合并。节奏照搬 Claude Code 终端里的 Critter：每格 60 毫秒，整像素跳动，不做补间；蹲下靠身体下沉、脚被地面挡住，而不是把身体压扁。

官方来自 Claude Code CLI 或 @claudeai 官方视频 新设计官方没有、为桌宠补的动作，沿用同一套手法

Notes

依据与落地

参考了什么

  • Claude Code CLI 2.1.302 本体。直接读了本机安装包里的动画数据：jump、look、tap、sneeze、waddle、boop、peekaboo、drop 等序列，每格 60 ms，眼睛会左右看、闭成 ▂ 线、眨单眼，手和脚一次挪一格，蹲下是下沉并裁掉脚，特效只有灰色 · ~ 和 ✦。
  • 思考指示符。· ✢ ✳ ✶ ✻ ✽ 按 2 秒余弦来回，在两端停得久一点。“运行中”头顶的指示符照这个节奏画成像素版。
  • @claudeai 官方视频：桌面版发布（走、张望、跳）、黑客松（挥旗）、Remote Control（举哑铃）、额度翻倍（跺脚撒彩纸）。帧级细节取自 Codrops 的逐帧复刻。
  • 社区桌宠：critter-on-desk 的目光跟随、抛球表示子任务，这两个点子借鉴了它。

设计原则

  • 守住官方手感。60 ms 一格、整像素位移、没有补间、不压扁；表情全靠眼睛和手。
  • 注意力分级。空闲和工作要安静：空闲 4–10 秒才做一个小动作，2 分钟后睡着；需要你的状态（提问、出错、完成）动作最大，一进入就有一下明显的“事件”动画。
  • 颜色只给状态用。身体永远是 #D97757，特效是灰色，只有头顶的 ? ✓ ! 和彩纸带状态色。
  • 进场有事件，循环要耐看。每个状态 = 一段单次进场 + 一段可以看很久的循环 + 随机小动作。
  • 减少动态效果：每个状态只停在一个代表姿势，不放粒子，展开合并直接到位。

怎么落到 App 里

  • 皮肤清单升级到 schema 2：parts 部件、poses 姿势、clips 动作（每格：姿势、格数、dx、dy、特效）、effects 粒子、states 状态（进场、循环、随机小动作、睡着时间）。这页的动画就是由同一份数据驱动的，换皮肤不用改代码。
  • 渲染走 Core Animation：姿势预先画成小位图；一段动作编译成 contents 和 position 两条离散关键帧，交给渲染进程播放，主线程不逐帧刷新，守住空闲 CPU 接近 0。
  • 交互复用现有的鼠标监听：点击穿透本来就在跟踪指针，顺手算出目光方向和“来回蹭”，只在方向变化时更新一次。
  • 拖动时窗口临时加宽：没被抓住的会落后最多 12 个像素再追上来，拖动期间给窗口四周留出这段余量，松手后收回。
  • 需要多记一个字段：工作动画按工具区分（抱笔记本改代码、思考、读、跑命令、子任务），状态文件要多存当前工具名。
  • 状态多一个“离场”动作：离开运行中时先合上笔记本，再接下一个状态的进场，清单里写成 exitBy。
