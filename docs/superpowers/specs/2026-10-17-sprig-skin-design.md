# 可选形象：小芽和它的伙伴们 — 设计文档

日期：2026-10-17
状态：已实现。

> 记号：**【用户定】** 用户明确做的决定；**【Claude 定】** Claude 代为决定、用户没有逐条确认的（用户要求跳过提问、直接做）。

- 可交互设计稿（**像素、动作、时间的唯一依据**，顶部可切换形象）：`docs/superpowers/specs/2026-10-17-sprig-motion-preview.html`
- 清单：`Skins/sprig`、`Skins/mochi`、`Skins/peep`、`Skins/bristle` 下的 `manifest.json`（schema 2），由 `node scripts/dev/make-skins-from-preview.js docs/superpowers/specs/2026-10-17-sprig-motion-preview.html Skins` 从设计稿生成。

## 1. 意图

默认形象 Clawd 是 Anthropic 的吉祥物。用户先要一个项目自己的形象（小芽 Sprig），随后决定：**默认仍是 Clawd【用户定】，另外几个形象都加到一个列表里供选择【用户定】**。列表里的是当时画过候选稿的四个：小芽、团子（猫）、啾啾（小鸡）、刺球（刺猬）。

## 2. 目标 / 非目标 / 反目标

### 目标
1. 四个原创形象，每个都覆盖动画 v2 的全部动作（五个状态的进场 / 循环 / 随机小动作、睡着、五种工作动作、全部交互和展开合并编排、减少动态效果）。
2. 设置里列出所有形象（Clawd 第一个、默认选中），选中后立即换上，不用重启；菜单栏图标跟着换。
3. 引擎几乎不动：沿用 schema 2、18×10 基准框、60 ms 一格，形象只是数据。

### 非目标
- 改 Clawd 的形象或动作（Clawd 的清单、设计稿、内置副本保持原样）。
- 每个形象各写一套动作编排。

### 反目标
- **像 Clawd 或其他知名形象。** 四个新形象不沿用 Clawd 的方块身体、橙色和 Claude Code 的 `· ✢ ✳ ✶ ✻ ✽` 思考符号；避开绿色圆顶加天线（Android）、蓝色刺猬等撞车造型。
- **缩小后认不出。** App 里一格 3 pt，整只 54×30 pt；菜单栏图标是 16 pt 剪影。
- **头顶的东西互相挡。** 头顶标记（太阳 / ? / ✓ / !）在第 −3 行及以上，形象平时不伸进去。
- **表情诡异。** 第一版小芽的 `^ ^` 眼配 4 格笑嘴被用户指出“太诡异”【用户定】，改为弧形闭眼 `∩ ∩` 加 2 格小嘴；欢呼时张小嘴露舌头。

## 3. 一家四口【Claude 定】

四个形象共用同一张脸的位置（2×2 带高光的眼睛、腮红、嘴）、同样的小短手和脚、同样的道具（笔记本、放大镜），所以姿势、动作、状态只写一份。各自不同的是：

| | 小芽 Sprig | 团子 Mochi | 啾啾 Peep | 刺球 Bristle |
|---|---|---|---|---|
| 是什么 | 头顶两片嫩叶的淡紫色圆豆子 | 蓝灰色圆猫，粉耳朵里、粉鼻头 | 黄色圆小鸡，奶油肚皮、橙色喙 | 刺猬：棕色刺团住奶油色小脸、黑鼻头 |
| 头顶那样东西 | 叶子 | 耳朵 | 呆毛 | 一排刺 |
| 有事 / 出错 / 睡着 / 在想 | 竖起 / 蔫下 / 合拢 / 像螺旋桨转 | 竖起 / 飞机耳 / 收起 / 抖一只 | 竖起 / 倒下 / 贴平 / 转起来 | 竖起 / 趴下 / 缩起 / 刺尖抖 |
| 做完了 | 叶子间开一朵花 | 两耳间别一朵花 | 呆毛旁开一朵花 | 刺上扎一颗苹果 |
| 嘴 | 共用 | 共用（深色） | 喙：闭着是身体的一部分，惊讶、欢呼时张开 | 共用 |
| 出错时掉下的 | 一片叶子 | 一撮毛 | 一根羽毛 | 一根刺 |
| 欢呼撒的 | 花瓣 + 叶子 | 花瓣 + 爱心 | 花瓣 + 羽毛 | 花瓣 + 小红果 |
| 抛的 | 三颗种子 | 三团毛线 | 三粒谷子 | 三颗浆果 |

当时还画过的候选和取舍：豆芽的圆轮廓和方块差别最大，选作第一个；刺猬第一版像“锅盖头的人”，重画成锯齿刺团加斜纹、圆脸、尖鼻头后才像刺猬；猫和小鸡第一稿就能认出来。

- **身形**：每个形象画一个正常身形，压扁（低一行、宽两格）和拉长（高一行、窄两格）由程序推导：压扁去掉第 5 行、复制两侧第 4 列；拉长复制第 4 行、删掉那两列。这样外轮廓、高光、鼻子、喙和刺纹都保留。小芽的三个身形是手画的。
- **头顶部件**：每个形象画正常、竖起、耷拉、压平、左右摇、思考、睡着几种，再加一朵花（或苹果）；花和各种变体的组合由程序拼出。
- **动作的手感**（四个共用）：弹性的压扁拉长；“运行中”头顶是自己的小太阳（5 帧，7 行高的框里居中，2 秒余弦来回）；思考时头顶部件转、读文件举放大镜、跑命令原地小跑、派子任务抛三个小东西；新会话从地里钻出来，结束时钻回地里；运行中不设随机小动作（眨眼会让笔记本和放大镜消失两格）。

## 4. 引擎改动：状态自己的目光姿势

“做完了”要一直顶着花，但引擎在“做完了”时会用 `interactions.look*` 替换当前姿势（目光跟随），花会在指针靠近时消失。为此加一个可选字段：

- `StateSpec.gaze`：`{ left, right, up, down, center }`，五个姿势名。有它的状态目光跟随时用这组，没有的沿用 `interactions.look*`。
- `MotionActor` 记住目光方向（`GazeZone`），取画面时按当前状态解析；状态变化后自动换成新状态的那组。
- `SkinValidator` 检查这五个姿势都存在。

四个新形象的 `done` 用了它；Clawd 不用，行为不变。

## 5. 形象列表【Claude 定】

- 清单可选字段 `title`（1–40 个字符），列表里显示它；没有时显示首字母大写的目录名（`clawd` → “Clawd”）。
- `SkinLibrary.available(searchDirs:)`：内置的 Clawd 排第一，然后是 `~/.critter/skins/` 和 App 自带 `Skins/` 里能解码、通过校验的皮肤，按名字排序；同名时先找到的有效那份胜出（`~/.critter/skins/` 优先，和 `SkinLoader.load` 一致）；名叫 `clawd` 的有效自定义皮肤替换第一格里的内置清单。列表在后台线程读。
- 设置 `skin`（默认 `clawd`）；设置窗口第一节“形象”是一排带缩略图（`base` 姿势，最近邻放大）的按钮，选中的有强调色边框。打开设置窗口时重新读列表，所以新放进 `~/.critter/skins/` 的皮肤下次打开就能看到。
- 切换：后台加载选中的皮肤（找不到或无效时退回 Clawd），回主线程后只采用最新一次选择的结果；像改大小一样重建宠物视图，会话、位置、显示 / 隐藏都保留；菜单栏图标用新皮肤的 `base` 姿势重画。`critter://debug-set?skin=<名字>` 走同一条路。
