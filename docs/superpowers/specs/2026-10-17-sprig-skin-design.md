## 1. 意图

默认形象 Clawd 是 Anthropic 的吉祥物。用户先要一个项目自己的形象（小芽 Sprig），随后决定：**默认仍是 Clawd【用户定】，另外几个形象都加到一个列表里供选择【用户定】**。列表里的是当时画过候选稿的四个：小芽、团子（猫）、啾啾（小鸡）、刺球（刺猬）。

## 2. 目标 / 非目标 / 反目标

### 目标
1. 四个原创形象，每个都覆盖动画 v2 的全部动作（五个状态的进场 / 循环 / 随机小动作、睡着、五种工作动作、全部交互和展开合并编排、减少动态效果）。
2. 设置里列出所有形象（Clawd 第一个、默认选中），选中后立即换上，不用重启；菜单栏图标跟着换。
3. 引擎几乎不动：沿用 schema 2、18×10 基准框、60 ms 一格，形象只是数据。

### 非目标
- 改 Clawd 的形象或动作（Clawd 的清单、设计稿、内置副本保持原样）。
- 每个形象各写一套动作编排。

### 反目标
- **像 Clawd 或其他知名形象。** 四个新形象不沿用 Clawd 的方块身体、橙色和 Claude Code 的 `· ✢ ✳ ✶ ✻ ✽` 思考符号；避开绿色圆顶加天线（Android）、蓝色刺猬等撞车造型。
- **缩小后认不出。** App 里一格 3 pt，整只 54×30 pt；菜单栏图标是 16 pt 剪影。
- **头顶的东西互相挡。** 头顶标记（太阳 / ? / ✓ / !）在第 −3 行及以上，形象平时不伸进去。
- **表情诡异。** 第一版小芽的 `^ ^` 眼配 4 格笑嘴被用户指出“太诡异”【用户定】，改为弧形闭眼 `∩ ∩` 加 2 格小嘴；欢呼时张小嘴露舌头。2026-10-23 用户又觉得 `∩ ∩` 加方块小嘴“不美观、怪异”，在三套备选里选定：**开心时眼睛照常睁着（带高光），配 U 形小嘴，欢呼时张成 ▽【用户定】**；腮红不变。

## 3. 一家四口【Claude 定】

四个形象共用同一张脸的位置（2×2 带高光的眼睛、腮红、嘴）、同样的小短手和脚、同样的道具（笔记本、放大镜），所以姿势、动作、状态只写一份。各自不同的是：

| | 小芽 Sprig | 团子 Mochi | 啾啾 Peep | 刺球 Bristle |
|---|---|---|---|---|
| 是什么 | 头顶两片嫩叶的淡紫色圆豆子 | 蓝灰色圆猫，粉耳朵里、粉鼻头 | 黄色圆小鸡，奶油肚皮、橙色喙 | 刺猬：棕色刺团成一个球、奶白刺尖围出锯齿边，中间一张小盾形奶白脸收成浅色吻部和黑鼻头（2026-10-23 重画，见下） |
| 头顶那样东西 | 叶子 | 耳朵 | 呆毛 | 一排刺 |
| 有事 / 出错 / 睡着 / 在想 | 竖起 / 蔫下 / 合拢 / 像螺旋桨转 | 竖起 / 飞机耳 / 收起 / 抖一只 | 竖起 / 倒下 / 贴平 / 转起来 | 竖起 / 趴下 / 缩起 / 刺尖抖 |
| 做完了 | 叶子间开一朵花 | 两耳间别一朵花 | 呆毛旁开一朵花 | 刺上扎一颗苹果 |
| 嘴 | 共用 | 共用（深色） | 喙：闭着是身体的一部分，惊讶、欢呼时张开 | 共用 |
| 出错时掉下的 | 一片叶子 | 一撮毛 | 一根羽毛 | 一根刺 |
| 欢呼撒的 | 花瓣 + 叶子 | 花瓣 + 爱心 | 花瓣 + 羽毛 | 花瓣 + 小红果 |
| 抛的 | 三颗种子 | 三团毛线 | 三粒谷子 | 三颗浆果 |

当时还画过的候选和取舍：豆芽的圆轮廓和方块差别最大，选作第一个；刺猬第一版像“锅盖头的人”，重画成锯齿刺团加斜纹、圆脸、尖鼻头后才像刺猬；猫和小鸡第一稿就能认出来。

**2026-10-23 刺球重画【用户定方向，Claude 定细节】：**用户觉得刺球还是“乱糟糟的棕头发围着一张方脸的小人”。原因是浅色脸占了下面三分之二、颜色又接近肤色，刺只剩一圈“发型”。改成：
- **刺团成整个球**：刺从头顶一直包到两侧和底部，外缘每隔一行伸出一个奶白刺尖（`T` `#E2C9A6`），形成锯齿轮廓；刺本身是深棕（`S` `#6F5546`），里面不再画斜纹（缩小后像棋盘格）。头顶的刺（`top`）同样是“刺尖 + 刺根”两行锯齿。
- **小盾形脸**：奶白（`B` `#F3DFC2`）的脸从额头中间两格往下展开，眼睛那两行最宽，往下收成两格宽的浅色吻部（`W` `#FFF6EA`），黑鼻头（`N`）在第 6 行吻部中间。共用的 U 形笑嘴正好弯在鼻子两边和下面；腮红（`blush`）往里收一格到第 5、12 列，不落在刺上；皱眉（`mouth_frown`）改成鼻子不动、两边嘴角往下。眼睛、惊讶的 o 嘴、欢呼的张嘴照用共用的。
- **试过不用的**：小圆耳朵（这个尺寸下像眉毛或第二对腮红）、刺里的斜纹和由深到浅的三层渐变（缩小后发花）。
- 头顶部件：平常两行锯齿；竖起三行、刺更长；趴下压成一条；睡着缩成光溜溜的一条弧（像团起来）；在想时刺尖挪到空隙里来回抖；做完了一颗带叶子的三行苹果扎在刺中间（`bloomBase` 中间四格留空给苹果）。掉落的刺颜色不变（`#6E5039`），所以 `bristle-states` 的 golden 不用重录。

- **身形**：每个形象画一个正常身形，压扁（低一行、宽两格）和拉长（高一行、窄两格）由程序推导：压扁去掉第 5 行、复制两侧第 4 列；拉长复制第 4 行、删掉那两列。这样外轮廓、高光、鼻子、喙和刺纹都保留。小芽的三个身形是手画的。
- **头顶部件**：每个形象画正常、竖起、耷拉、压平、左右摇、思考、睡着几种，再加一朵花（或苹果）；花和各种变体的组合由程序拼出。
- **动作的手感**（四个共用）：弹性的压扁拉长；“运行中”头顶是自己的小太阳（5 帧，7 行高的框里居中，2 秒余弦来回）；思考时头顶部件转、读文件举放大镜、跑命令原地小跑、派子任务抛三个小东西；新会话从地里钻出来，结束时钻回地里；运行中不设随机小动作（眨眼会让笔记本和放大镜消失两格）。

## 4. 引擎改动：状态自己的目光姿势

“做完了”要一直顶着花，但引擎在“做完了”时会用 `interactions.look*` 替换当前姿势（目光跟随），花会在指针靠近时消失。为此加一个可选字段：

- `StateSpec.gaze`：`{ left, right, up, down, center }`，五个姿势名。有它的状态目光跟随时用这组，没有的沿用 `interactions.look*`。
- `MotionActor` 记住目光方向（`GazeZone`），取画面时按当前状态解析；状态变化后自动换成新状态的那组。
- `SkinValidator` 检查这五个姿势都存在。

四个新形象的 `done` 用了它；Clawd 不用，行为不变。

## 5. 形象列表【Claude 定】

- 清单可选字段 `title`（1–40 个字符），列表里显示它；没有时显示首字母大写的目录名（`clawd` → “Clawd”）。
- `SkinLibrary.available(searchDirs:)`：内置的 Clawd 排第一，然后是 `~/.critter/skins/` 和 App 自带 `Skins/` 里能解码、通过校验的皮肤，按名字排序；同名时先找到的有效那份胜出（`~/.critter/skins/` 优先，和 `SkinLoader.load` 一致）；名叫 `clawd` 的有效自定义皮肤替换第一格里的内置清单。列表在后台线程读。
- 设置 `skin`（默认 `clawd`）；设置窗口第一节“形象”是一排带缩略图（`base` 姿势，最近邻放大）的按钮，选中的有强调色边框。打开设置窗口时重新读列表，所以新放进 `~/.critter/skins/` 的皮肤下次打开就能看到。
- 切换：后台加载选中的皮肤（找不到或无效时退回 Clawd），回主线程后只采用最新一次选择的结果；像改大小一样重建宠物视图，会话、位置、显示 / 隐藏都保留；菜单栏图标用新皮肤的 `base` 姿势重画。`critter://debug-set?skin=<名字>` 走同一条路。

## 8. 第二批：六六、噗噗、菇菇【Claude 定】

日期：2026-10-23。默认形象不再绑定某一家的吉祥物以后，又加了三个原创形象，做法和前四个完全一样：在设计稿的 `SKIN BEGIN … SKIN END` 数据块里各写一份 `art`，交给 `make(...)`，共用同一套脸、手脚、道具、姿势、动作和状态；压扁和拉长的身形由程序推导。前四个形象的数据和清单一个字节都没动（刺球后来单独重画过，见 §3）。

| | 六六 Frill | 噗噗 Spout | 菇菇 Bonnet |
|---|---|---|---|
| 是什么 | 粉色六角恐龙：和小芽一样的圆身子，脑袋两侧各三根羽毛鳃（朝上、斜着、朝外，像一把小扇子），鳃根深、鳃尖浅（2026-10-23 重画，见下） | 天蓝色圆鲸鱼，底部一小块浅蓝肚皮，头顶一股小水柱 | 奶白色的小蘑菇精灵，戴一顶带荧光斑点的薄荷色蘑菇帽，帽檐比身子宽一格 |
| 主色 | 身体 `#FFC9D9`、阴影 `#F0A2BC`、鳃 `#FF6F98`、鳃根 `#E0507C`、鳃尖 `#FFA6C0`、腮红 `#FF8FB0` | 身体 `#86C5F2`、阴影 `#5E9FD6`、肚皮 `#C4E6FB`、水花 `#D9F3FF`、水柱 `#9ED8F7` | 身体 `#F6EBDD`、帽子 `#5FCDB2`、帽檐 `#3E9F8E`、斑点 `#E4FFF6` |
| 头顶那样东西 | 鳃 | 水柱 | 蘑菇帽 |
| 有事 / 出错 / 睡着 / 在想 | 一起向上扬起 / 垂到脸两侧 / 收成两个小点 / 一边的鳃扬起、一边不动，来回扑扇 | 喷高 / 塌下来淋一头 / 只剩一个小水泡 / 一开一合地咕嘟 | 跳起一格露出脑门 / 帽檐两边耷拉 / 拉低盖住额头、斑点熄掉 / 斑点换位置，像帽子在转 |
| 做完了 | 鳃扬起，中间开一朵小雏菊（白瓣黄心） | 水柱顶起一朵小花 | 帽子上开一朵小花 |
| 出错时掉下的 | 一个小泡泡 | 一颗水珠 | 一粒发光的孢子 |
| 欢呼撒的 | 花瓣 + 泡泡 | 花瓣 + 水滴 | 花瓣 + 孢子 |
| 抛的 | 浅蓝、白、黄三颗小珠子 | 粉、黄、浅蓝三颗小球 | 薄荷、粉、黄三颗孢子 |

- **避开撞车**：不用 Clawd 的橙色方块身体和 `✻` 一类思考符号；鲸鱼不画成某个知名吉祥物的样子，蘑菇不用红帽白点（避开游戏里的蘑菇道具），也不画成带波浪下摆的幽灵（避开吃豆人的幽灵）。七个形象的主色分别落在淡紫、蓝灰、黄、棕、粉、天蓝、薄荷，互不相同。
- **头顶部件不挡手**：头顶部件最后画，会盖住手。六六的鳃伸到身体两侧，所以凡是会和举起的手同时出现的变体（竖起、左右摇、开花，以及拉长时的竖起和开花）都只用第 −1 行及以上、离手至少一格：不碰举手用的格子（第 0 列的第 0 行、第 1 列的第 1、2 行，右边对称）也不和它们相邻；“有事找你”、挥手、抛东西、被拎起、欢呼时手都完整可见。
- **2026-10-23 六六重画【用户定方向，Claude 定细节】**：用户觉得第一版“又宽又扁像块砖、鳃乱糟糟”，在三个草稿里选了“更圆的身子 + 两侧各三根更长的羽毛鳃、向上向外散开”。定稿：身子直接用小芽的圆轮廓；平常每侧三根鳃从脑袋上角长出——一根竖直、一根斜向外上、一根朝外，每根三格，鳃根 `g` 深、鳃尖 `F` 浅，中间留空，不再挤成一团；竖起时整把扇子转到头顶两角朝上（第 −3 到 −1 行），左右摇是竖起的扇子整体左右挪一格；垂下时鳃挂到脸两侧；压扁时三根横贴在头两角；睡着收成两个浅色小点；在想时一侧扬起、一侧平常，和平常姿势来回切换就是扑扇。草稿里鳃尖压在举起的手上、欢呼时盖住手，定稿都避开了。
- **菇菇的帽子就是头顶部件**：帽子占第 −2 到 1 行、比身体窄的上半身宽一格，所以看起来是帽檐；身体最上两行被帽子盖住，帽子跳起时才露出来。思考时 `top` 和 `top_edge` 两顶帽子斑点位置不同，来回切换就像帽子在转。
- **噗噗的肚皮**：第一稿用接近白色的整条肚皮，配上嘴像一排牙，改成底部一小块浅蓝。
- **设计稿**：顶部切换器、色板、说明（`SKIN_INFO`）和“头顶那样东西”的提示都加了这三个；`#frill`、`#spout`、`#bonnet` 直接打开对应形象。
